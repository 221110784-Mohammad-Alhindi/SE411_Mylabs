# SE411 Main Project

## Project Overview

This project was created for the SE411 Software Engineering course.

The project demonstrates the use of Java, JavaFX, Maven, and Git in a software engineering project.

## Technologies Used

- Java 21
- JavaFX 23
- Maven
- Eclipse IDE
- Git and GitHub

## Main Features

- Java-based application
- JavaFX graphical user interface
- Maven dependency management
- Maven-generated project documentation
- Git and GitHub version control
